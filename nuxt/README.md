# NomadCore — Nuxt 3 / Vue 3 / Tailwind

Код для прототипа NomadCore.dc.html. Библиотека компонентов не подключается: все примитивы свои.

## Бюджет веса (первая загрузка владельца, gzip)

Считается ровно то, что скачивает владелец при первом открытии на дешёвом
Android. Кабинет госагентства (`/gov/*`) в этот бюджет НЕ входит: это
отдельный маршрут, отдельный чанк и другое устройство.

| Что | Оценка |
|---|---|
| Nuxt 3 runtime + Vue 3 | ~ 42 КБ |
| vue-router (4 маршрута владельца) | ~ 11 КБ |
| dexie | ~ 24 КБ |
| наш код: 9 примитивов, 4 страницы, composables, словарь ru+kg | ~ 16 КБ |
| **Итого на первую загрузку** | **≈ 93 КБ** |
| `/gov/occupancy` — отдельный чанк, грузится только в кабинете | + ~ 6 КБ |

Чем бюджет держится: библиотеки компонентов нет, иконочного шрифта нет
(12 путей в `NcIcon.vue`), веб-шрифтов нет (системный стек), библиотеки дат
нет (`utils/dates.ts` — 40 строк на полуинтервалах), библиотеки графиков нет
(три рисунка в кабинете — инлайновый SVG), i18n-библиотеки нет
(`useI18n.ts` — один ref и словарь), плюрализация своя (`utils/plural.ts`).
Dexie грузится динамически из `useSync`, чтобы не блокировать первый экран.

Правила, которые держат бюджет:
- `ssr: false` + prerender оболочки: приложение стартует из кэша, без ожидания сети.
- Никаких иконочных шрифтов и веб-шрифтов — системный стек и 12 инлайновых SVG в `components/icons`.
- Никаких chart-библиотек в приложении владельца. Графики есть только в кабинете госагентства — это отдельный вход (`pages/gov`), он грузится своим чанком и не входит в бюджет владельца.
- Dexie импортируется динамически из `useSync`, чтобы не блокировать первый экран.

## Занятость: почему «Ночи», а не «Сетка»

Три подхода сравнивались живьём на 360px — файл `NomadCore Занятость 360.dc.html`.
Замер по числу тапов до ответа:

| Вопрос владельца | День | Сетка | Ночи |
|---|---|---|---|
| «Что у меня сегодня?» | **0** | 2 | 1 |
| «Есть места в субботу?» | 1 | 1 + скролл вбок | **1** |
| «Когда 2 свободные ночи подряд?» | 5+ | 1 + сканирование 140 клеток | **1** |
| «Куда переселить из номера 2?» | 3+ | **1 + скролл** | 2 |
| Одной рукой | да | **нет** | да |

Вывод, который расходится с ожиданием: на 360px сетка не выигрывает ни одного
вопроса, кроме перемещения между номерами. Её основную работу — «свободно ли
на выходные» — быстрее и одной рукой делает список ночей. Поэтому порядок
режимов: **День** (умолчание) → **Ночи** → **Сетка**.

Полуинтервал `[checkIn, checkOut)` читается однозначно во всех трёх:
в «Дне» стык подписан словами («Ким Мария → Chen Wei»), в «Сетке» полоса идёт
от середины дня заезда до середины дня выезда (соседние брони касаются, но не
накладываются), а в «Ночах» ошибиться нельзя по построению — строка и есть
ночь, у неё ровно один постоялец.

## Открытый вопрос к бэкенду

Спроектированный офлайн-слой **меняет контракт разрешения конфликтов**:
вместо last-write для дат и статуса выбор делает владелец. Это не деталь
вёрстки — требуется работа на стороне API (тело в ответе 409, журнал
изменений с автором, разделение 409/422). Задача, обоснование и разделение
полей: `API-CONFLICTS.md`. До её выполнения экран конфликта работает
в урезанном виде.

## Структура

```
types/index.ts            Property, RoomType, Room, Guest, Booking, статусная машина
utils/dates.ts            полуинтервалы [checkIn, checkOut), таймзона объекта
lib/db.ts                 Dexie: кэш GET + очередь мутаций
composables/useSync.ts    очередь, ретраи, 409/version, разрешение конфликта
composables/useAvailability.ts  сетка номер x дни, «стык» без ложного пересечения
composables/useI18n.ts    ru / kg
components/NightsList.vue      режим «Ночи» — выбранный второй режим
components/AvailabilityGrid.vue режим «Сетка» — третий, для перемещений
components/*.vue               остальные свои компоненты
composables/useNationalStats.ts агрегаты кабинета: всё производное
pages/index.vue                Сегодня
pages/occupancy.vue            Занятость: День / Ночи / Сетка
pages/booking/-id-.vue         Карточка брони
pages/queue.vue                Очередь мутаций
pages/gov/occupancy.vue        Кабинет госагентства, шкала desk

../design-system/tokens.css    подключается первым; литералов в компонентах нет
```

## Доступность и поле

- Основной текст #111310 на #FFFFFF — 17.4:1. Вторичный #4A4C48 — 8.6:1.
- Тач-таргеты: `min-h-touch` = 44px, основные действия 64px, в нижней трети экрана.
- Переходы только на смену состояния (120–160 мс), `prefers-reduced-motion` уважается.
- Кыргызский длиннее русского: ни одна кнопка не имеет фиксированной ширины, только `min-w`.

## Одно замечание по именам файлов

Файловая система этого проекта не хранит квадратные скобки, поэтому динамический
маршрут лежит как `pages/booking/-id-.vue`. При переносе в репозиторий
переименуйте его в `pages/booking/[id].vue` — иначе Nuxt не увидит параметр.
