# NomadCore — UI Design Document

**Версия:** 1.0 · **Дата:** 23.07.2026
**Приложение:** `apps/web` (Nuxt 3 PWA, offline-first)
**Связанные документы:** `docs/DESIGN.md` (архитектура и ADR)

---

## 1. Контекст и принципы

Основной пользователь — владелец/хозяйка гостевого дома (пилот: Каракол, Иссык-Куль):
недорогой Android, нестабильный интернет, работа одной рукой «на ходу», языки — кыргызский и русский.

**Принципы UI:**

1. **Телефон прежде всего.** Один столбец контента, нижняя таб-навигация в зоне большого пальца. Десктоп — просто широкий телефон, без отдельных раскладок в MVP.
2. **Крупные цели касания.** Минимальная сенсорная цель — 44×44 px (токен `--tap`). Кнопки действий — полноразмерные, а не иконки.
3. **Статус данных всегда виден.** Бейджи «Офлайн» и «Не синхронизировано: N» в шапке. Пользователь никогда не гадает, сохранились ли изменения (см. ADR-5/ADR-6 в DESIGN.md).
4. **Минимум текста, максимум статусов.** Статусная машина брони (HOLD → CONFIRMED → CHECKED_IN → CHECKED_OUT / CANCELLED) визуализируется цветными бейджами — единая палитра во всех экранах.
5. **Два языка равноправны.** Все строки через i18n (`ru.json` / `ky.json`), переключение в один тап в Настройках. Никаких строк, зашитых в шаблоны (кроме валюты «сом»).
6. **Дёшево и быстро.** Системные шрифты, без UI-библиотек и icon-fonts (иконки — эмодзи), CSS-токены вместо препроцессоров. Целевой бюджет JS — минимальный для дешёвых устройств.
7. **Красная линия монетизации.** UI бесплатного тарифа никогда не блокирует учёт и анти-овербукинг; Pro-функции подсвечиваются, но не мешают (ADR-7).

## 2. Дизайн-токены

Единственный источник правды — `:root` в `apps/web/app.vue`.

### 2.1 Бренд и поверхности

| Токен | Значение | Использование |
|---|---|---|
| `--brand` | `#1c4532` | Шапка, primary-кнопки, активный таб |
| `--brand-strong` | `#143725` | Нажатое состояние primary |
| `--brand-soft` | `#e7f0eb` | Фон активного таба, колонка «сегодня» в календаре |
| `--accent` | `#f59e0b` | Бейдж синхронизации |
| `--bg` | `#f6f7f6` | Фон приложения |
| `--surface` | `#ffffff` | Карточки, таббар, модалки |
| `--border` | `#e3e6e4` | Разделители, рамки карточек |
| `--text` | `#1f2937` | Основной текст |
| `--muted` | `#6b7280` | Вторичный текст |
| `--danger` | `#b91c1c` | Разрушающие действия (отклонить, выйти) |

### 2.2 Цвета статусов брони

Маппинг статусной машины из DESIGN.md (§4, ADR-3) на цвета. Классы бейджей: `.badge.st-<STATUS>`.

| Статус | Текст | Фон | Смысл |
|---|---|---|---|
| `HOLD` | `#b45309` | `#fef3c7` | Заявка из бота, требует решения |
| `CONFIRMED` | `#15803d` | `#dcfce7` | Подтверждена, ждём заезда |
| `CHECKED_IN` | `#1d4ed8` | `#dbeafe` | Гость проживает |
| `CHECKED_OUT` | `#4b5563` | `#f3f4f6` | Завершена |
| `CANCELLED` | `#b91c1c` | `#fee2e2` | Отменена |

Правило: жёлтый/янтарный всегда означает «требует внимания» (HOLD, несинхронизировано), красный — только ошибки и отмены.

### 2.3 Геометрия и типографика

| Токен / правило | Значение |
|---|---|
| `--radius` / `--radius-sm` | 12 px (карточки) / 8 px (кнопки, поля) |
| `--shadow` | `0 1px 3px rgba(0,0,0,.08)` — только на карточках |
| `--tap` | 44 px — min-height кнопок, полей, табов |
| Шрифт | `system-ui` стек, без веб-шрифтов |
| Базовый размер | 16 px (и не меньше 16 px в полях ввода — иначе iOS/Android зумят) |
| H1 / H2 | 22 px / 16 px |
| Вторичный текст | 13 px, `--muted` |
| Отступы | Шкала 4/8/12/16/20; страница — 16 px по краям |

## 3. Компоненты

### 3.1 Topbar (шапка)
- Sticky, фон `--brand`, логотип слева.
- Справа зона системных бейджей: `Офлайн` (тёмно-серый) и `Не синхронизировано: N` (янтарный). Появляются только при необходимости.
- Учитывает `safe-area-inset-top`.

### 3.2 Tabbar (нижняя навигация)
- 5 фиксированных вкладок: Сегодня 🏠 · Календарь 📅 · Номера 🛏️ · Гости 👥 · Настройки ⚙️.
- Иконка (эмодзи 20 px) + подпись 11 px. Активная вкладка — цвет `--brand`, фон `--brand-soft`.
- Учитывает `safe-area-inset-bottom`; контент страницы имеет нижний отступ под таббар.

### 3.3 Кнопки
- **Primary** — заливка `--brand`, белый текст, вес 600. Одно главное действие на карточку/форму.
- **Secondary (default)** — белая с рамкой `--border`. Навигация, второстепенные действия.
- **Danger** — прозрачная, красный текст и мягкая красная рамка. «Отклонить», «Выйти».
- Все кнопки ≥ 44 px высотой, `:active` — лёгкое сжатие (scale 0.98), `:focus-visible` — обводка `--brand`.

### 3.4 Карточки (`.card`)
- Поверхность `--surface`, рамка `--border`, радиус `--radius`, тень `--shadow`, внутренний отступ 12 px.
- Карточка брони: имя гостя + статусный бейдж в первой строке, метаданные (номер, даты, цена) вторичным текстом, действия — ряд кнопок снизу.

### 3.5 Бейджи (`.badge`)
- Пилюля 12 px, вес 600. Варианты: статусы брони (§2.2), sync, offline.

### 3.6 Поля ввода
- 16 px текст, высота ≥ 44 px, радиус `--radius-sm`. Подпись над полем (label-сверху), не placeholder-only для обязательных полей.

### 3.7 Модальное окно
- Оверлей `rgba(0,0,0,.4)`, диалог по центру, радиус `--radius`, закрытие по тапу на фон и по кнопке «Отмена».
- Используется только для создания брони из календаря. Формы длиннее 4 полей — отдельным экраном, не модалкой.

## 4. Экраны

### 4.1 Вход (`/login`)
- Брендовый блок (лого-круг, название, слоган) + карточка с формой.
- Шаг 1: телефон (+996…) и имя → «Получить код». Шаг 2: OTP-код (`inputmode=numeric`, `autocomplete=one-time-code`).
- Ошибка — красной строкой под формой, без алертов.

### 4.2 Сегодня (`/`) — главный экран
- Сводка-чипы: Заявки / Заезды / Выезды с количеством.
- Секция **Заявки из бота** (видна только если есть HOLD): карточка с янтарной рамкой, действия «Подтвердить» (primary) / «Отклонить» (danger). Это самая приоритетная секция — всегда сверху.
- Секции **Заезды** (CONFIRMED на сегодня → кнопка «Заселить») и **Выезды** (CHECKED_IN c выездом сегодня → «Выселить»).
- Пустые состояния — короткая muted-строка «На сегодня ничего нет».

### 4.3 Календарь (`/calendar`) — шахматка
- Панель: ← неделя · заголовок · «Сегодня» · неделя →. Горизонт — 14 дней.
- Сетка: строки — номера (первая колонка sticky), колонки — даты (ДД.ММ, выходные подсвечены), колонка текущего дня — фон `--brand-soft`.
- Ячейки: свободно — белая (тап → модалка новой брони), HOLD — янтарная, занято — голубая. Легенда под сеткой.
- Ошибка `OVERBOOKING` от API показывается в модалке человеческим текстом (i18n `booking.overbooking`) — UI-проявление ADR-1.

### 4.4 Номера (`/rooms`)
- Два блока: «Типы номеров» и «Номера» — списки карточек + форма добавления в карточке.

### 4.5 Гости (`/guests`)
- Поиск с debounce 300 мс. Карточка гостя: аватар-инициал, имя, телефон ссылкой `tel:`, разворачиваемая история броней со статусными бейджами.

### 4.6 Настройки (`/settings`)
- Язык — сегмент-переключатель ru/ky (один тап, без сохранения).
- Объект — форма (название, регион) + «Сохранить» с индикатором ✓.
- Подписка — карточка с бейджем FREE/PRO и напоминанием о «красной линии» (учёт бесплатен всегда).
- «Выйти» — danger-кнопка внизу.

## 5. Состояния системы

| Состояние | Проявление в UI |
|---|---|
| Офлайн | Бейдж «Офлайн» в шапке (слушатели `online`/`offline`); чтение — из кэша SW/Dexie |
| Несинхронизировано | Янтарный бейдж «Не синхронизировано: N» (`syncPending` из `useSession`) |
| Пустой список | Короткая muted-строка, без иллюстраций (экономия веса) |
| Ошибка формы | Красная строка рядом с формой; код `OVERBOOKING` — специальный текст |
| Загрузка | SSR/await до отрисовки; скелетоны — не в MVP |

---

## 6. Доступность и производительность

- Сенсорные цели ≥ 44 px; контраст текста ≥ 4.5:1 (проверено для палитры §2).
- `:focus-visible` для всех интерактивных элементов; эмодзи-иконки в табах — `aria-hidden`, подпись текстом.
- Размер шрифта в инпутах ≥ 16 px (анти-zoom).
- Без сторонних UI-библиотек, icon-fonts и веб-шрифтов; иконки — эмодзи; вся стилизация — глобальные токены + scoped CSS.

---

## 7. Реализация

- Токены и базовые компоненты (кнопки, карточки, бейджи, таббар, поля) — глобальный `<style>` в `apps/web/app.vue`.
- Каркас (topbar + tabbar + офлайн-детекция) — `layouts/default.vue`.
- Экранные стили — scoped `<style>` в страницах, только специфичное для экрана.
- Новые строки UI добавляются одновременно в `i18n/locales/ru.json` и `ky.json`.

## 8. Дальнейшие шаги (вне текущей итерации)

1. Скелетоны/оптимистичные обновления для действий со статусами.
2. Растягивание брони на диапазон ячеек в шахматке (drag) — после пилота.
3. Тёмная тема (токены уже позволяют).
4. Экран деталей брони (сейчас статусы меняются с «Сегодня»).
